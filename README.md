
# 📝 To-Do List App

A simple and interactive **To-Do List web application** built using HTML, CSS, and jQuery. It allows users to add tasks, mark them as completed, and delete tasks through a user-friendly interface.

## 📸 Screenshot

![To-Do List App](https://github.com/RabadeJanhvi-45/To-Do-List-App/assets/91745609/8e1b8c99-6858-4ddd-9f52-f03916483395)

## ✨ Features

- ➕ Add new tasks to your to-do list.
- ✅ Mark tasks as completed.
- 🗑️ Delete tasks when they are no longer needed.
- ⚡ Dynamically update the task list using jQuery.
- 🎨 Simple and user-friendly interface.

## 🛠️ Tech Stack

- **HTML5** – Application structure.
- **CSS3** – Styling and layout.
- **jQuery** – Event handling and DOM manipulation.

## ⚙️ How It Works

1. Enter a task in the input field.
2. Add it to the task list.
3. Mark the task as completed when finished.
4. Delete tasks that are no longer required.

> **Note:** Tasks remain available during the current page session but are cleared when the page is refreshed. Persistent storage is not implemented.

